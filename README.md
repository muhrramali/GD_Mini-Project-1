# Desert Oasis Caravan Stop

A top-down/exploratory Unity mini-project (**CSE-411 Mini Project 1 — Theme 2**) depicting a desert caravan rest stop set in a low basin surrounded by rolling dunes and a distant sandstone gateway[cite: 1].

## Overview

- **Route & Layout:** Leads from **1. Arrival ridge** through **2. Caravan camp** (tents, goods, and a cart) to **3. Oasis shore** beside the **Oasis basin**, with a sandstone gateway serving as a distant landmark
- **Lighting & Mood:** Warm high directional light with sharp sand shadows, desert sky and dust-colored fog on distant dunes, palm and canvas shade around teal water, and warm point lights with emissive lanterns in camp
- **Tech & Assets:** Built in Unity using **URP**, with AI-assisted terrain, blended sand layers, primitive scenery, layout, lighting, and C# scripts alongside a credited **3rd Person Controller + Fly Mode** package for character movement, flight animations, and camera control
- **Walkthrough:** Includes `Caravan Stop Walkthrough.mp4` (1 min 24 sec play-mode walkthrough) in the submission files[cite: 1]
